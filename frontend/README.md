# Frontend

React-based frontend for the Digital Certificate Verification System.

## Technology

* React
* Vite
* JavaScript
* HTML
* CSS

## Responsibilities

The frontend handles:

* User interface
* Certificate verification
* Certificate search
* User authentication interface
* Dashboards
* Form validation
* Communication with the Java backend through REST APIs

## Project Structure

```text
frontend/
├── src/
├── public/
├── package.json
└── README.md
```

## Setup

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will normally be available at:

```text
http://localhost:5173
```

## Backend API

The frontend communicates with the Java backend through REST APIs.

Default development backend:

```text
http://localhost:8080
```
